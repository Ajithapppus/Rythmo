# Rythmo
Static music web app (GitHub Pages). Search English, Malayalam, Hindi and Tamil songs, 30-second previews via the iTunes Search API.
Upload all files to the repo root and enable Pages (Settings > Pages > Deploy from branch > main / root).

## Full songs + sleep timer
1. Get a free client ID at https://developer.jamendo.com (create an app).
2. In `index.html`, replace `YOUR_CLIENT_ID` with it.
3. Choose "Full songs (free licensed music)" under the search bar.
Sleep timer: dropdown in the player (15/30/45/60 min or end of song, with a fade-out).
